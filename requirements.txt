# 版本策略：下界（>=）保证最低可用，上界（<）锁定到下一大版本，避免上游 breaking

# 可复现构建：requirements.lock 是本机开发解释器（Python 3.14.6）的全量环境快照，
#   含测试与静态检查工具，用于复现开发/CI 环境；目标环境 Python 版本不同时，
#   请在该环境下重新 `pip freeze` 生成。生产镜像直接用本文件即可。

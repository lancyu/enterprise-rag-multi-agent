一、产品概述

Q1：星河智能云平台是什么？
星河智能云平台是面向企业级客户的一站式 AI 应用开发与运营平台，提供模型接入、知识库管理、智能体编排、应用发布与运营分析五大能力模块，支持公有云、私有化与混合部署三种交付形态。

Q2：平台支持接入哪些大模型？
平台已内置对主流大模型的统一接入能力，包括通用大模型、代码大模型、多模态大模型与向量模型。客户可通过标准协议接入任意第三方模型服务，也可接入企业自有的本地模型服务。所有模型通过统一网关调度，支持按业务场景路由不同模型。

Q3：平台的核心优势是什么？
一是模型无关，上层业务不绑定任何单一模型，可随时切换；二是知识闭环，内置企业级 RAG 引擎，支持多格式文档解析与增量更新；三是安全合规，支持私有化部署与数据不出域；四是开箱即用，提供可视化编排界面，业务人员无需编码即可搭建智能应用。

二、部署与接入

Q4：平台支持哪些部署方式？
平台支持三种部署形态：公有云 SaaS 版，开通账号即可使用，按调用量计费；私有化部署版，部署于客户自有服务器或专属云环境，数据完全本地化；混合部署版，编排与控制面在云端，数据面与知识库在客户本地。

Q5：私有化部署的硬件要求是什么？
最小生产环境建议配置：控制节点 8 核 16 GB 内存、200 GB SSD；计算节点 16 核 32 GB 内存、500 GB SSD；如需本地运行大模型推理，建议配置 GPU 节点。向量库与缓存服务可与控制节点共用，数据量超过百万片段时建议独立部署。

Q6：部署周期大概多久？
公有云版本即时开通；私有化标准版从环境准备到验收交付通常为 10 至 15 个工作日，含环境部署、知识库初始化、业务配置与培训。涉及定制开发的项目周期根据需求评估确定。

Q7：如何完成首次接入？
完成部署后，管理员登录控制台，依次完成以下操作：创建组织与成员、配置模型服务密钥、创建知识库并上传文档、搭建智能体编排流程、发布应用并获取调用接口。平台提供开箱即用的模板，可直接复制使用。

三、知识库功能

Q8：知识库支持哪些文档格式？
支持 PDF、Word、PPT、Excel、Markdown、TXT、HTML 等常见格式，同时支持通过接口推送结构化文本。单次上传文件大小上限为 50 MB，单篇文档字符数上限为 50000 字符。

Q9：文档更新后需要重新上传吗？
文档内容修改后，在知识库管理页面点击该文档的"重新解析"即可增量更新，无需重新上传。若批量调整了多篇文档，可使用"重建索引"功能全量刷新，重建期间检索服务不中断。

Q10：检索结果不准确怎么办？
可从以下方面优化：第一，检查文档切片是否过大或过小，建议将分片调整为 300 至 500 字符；第二，适当降低相似度阈值以召回更多候选；第三，为文档补充标题与摘要，提升语义表征质量；第四，开启重排序模型对候选结果二次排序。平台提供检索调试面板，可实时查看候选片段与匹配分数。

四、计费与授权

Q11：平台如何计费？
公有云版本按调用量与知识库存储量计费，提供免费额度与阶梯定价；私有化版本按部署节点数与并发授权数收取年度许可费，含首年技术支持服务。具体报价请联系客户成功经理。

Q12：是否提供试用？
平台提供 30 天免费试用，包含全部功能模块，token 额度为 100 万，知识库容量 1 GB。试用期数据可无缝迁移至正式版。

五、运维与支持

Q13：平台的服务可用性如何保障？
公有云版本承诺 99.9% 的月度服务可用性，采用多可用区部署与自动故障转移。私有化版本提供监控告警组件，可对接客户自有运维平台。平台支持全链路日志追踪，所有请求可回溯。

Q14：遇到故障如何报修？
可通过三种方式报修：在控制台提交工单、拨打 7×24 技术支持热线、联系专属客户成功经理。紧急故障（P0）响应时间为 30 分钟，一般问题（P2）为 4 小时内响应。

Q15：数据安全性如何保障？
平台通过等保三级认证。传输层采用 TLS 加密，存储层支持透明加密；支持细粒度权限控制与操作审计；支持数据自动备份与异地容灾。私有化部署场景下，所有数据留存于客户环境，平台不采集任何业务数据。

六、智能体与编排

Q16：什么是智能体（Agent）？
智能体是将检索、模型调用与业务工具编排为可复用流程的自动化应用。平台提供可视化编排界面，支持条件分支、并行执行与人工介入节点，业务人员无需编码即可搭建。

Q17：如何创建一个智能体？
登录控制台进入"智能体"模块，选择模板或从空白开始：添加入口节点接收用户输入，接入知识库检索节点，串联生成节点与业务工具节点，最后配置输出节点。编排定义以 JSON 描述节点与边，可版本化管理。

Q18：智能体支持调用外部工具吗？
支持。平台提供工具注册机制，可将内部 API 或第三方服务注册为工具，智能体在推理过程中按需调用并回填结果。工具调用须配置权限与超时，异常时自动降级到纯检索生成。

七、集成与开放生态

Q19：平台支持哪些集成方式？
平台提供标准 REST API、Webhook 与事件总线三种集成方式，可对接企业微信、飞书、钉钉等 IM 渠道，也可嵌入自有业务系统。详情见《开发者 API 接入指南》。

Q20：能否把智能体嵌入官网或小程序？
可以。平台生成可嵌入的对话组件与 iframe 脚本，支持自定义样式与身份鉴权，也可通过 API 自行开发前端。嵌入前须在控制台配置可信域名白名单。

Q21：是否提供 SDK？
平台提供 Python 与 JavaScript 官方 SDK，封装鉴权、限流重试与流式解析，降低接入成本。社区维护的 Go、Java 封装可由开发者自行引入。

八、客户案例与最佳实践

Q22：有哪些典型落地场景？
一是企业内部知识助手（制度/IT 问答），二是售前方案自动生成，三是客服工单辅助，四是数据分析自然语言查询。金融、制造与软件行业已有规模化落地。

Q23：上线后如何持续优化？
建议建立"评测—反馈—迭代"闭环：用真实问答评测集定期回归，结合用户反馈标记错误回答，回流补充知识库或调整切片与提示词。平台提供检索调试面板与评测报告，量化每次迭代收益。
